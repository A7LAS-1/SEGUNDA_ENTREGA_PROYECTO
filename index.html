Arquitectura del Sistema & Integridad Referencial

Proyecto de Bases de Datos • ESCOM IPN • Base de Datos seguros_db

1

Frontend Web (GitHub Pages)

Captura de formularios con validación estricta (Regex RFC ^[A-Z&Ñ]{3,4}[0-9]{6}[A-Z0-9]{3}$, CP 5 dígitos, teléfono 10 dígitos) y sincronización con túnel Cloudflare.

2

Capa de Backend (FastAPI + Docker)

Procesa peticiones HTTP JSON, ejecuta transacciones ACID y mapea la jerarquía de herencia de vehículos (VEHICULO con subtipos AUTOMOVIL y MOTOCICLETA).

3

PostgreSQL (Puerto 5432)

Base de datos normalizada con restricciones ON DELETE RESTRICT / CASCADE, dominios de integridad y tipos numéricos de alta precisión para pólizas y reclamaciones.

Reglas de Integridad Referencial Destacadas

  • CLIENTE a POLIZA: ON DELETE RESTRICT para proteger pólizas activas ante eliminaciones accidentales de clientes.
  • VEHICULO a AUTOMOVIL / MOTOCICLETA: Relación de supertipo/subtipo con integridad estricta de matrícula.
  • RECLAMACION a PAGO_RECLAMACION: Llave foránea compuesta (ID_ACCIDENTE, NUM_POLIZA, NUM_DE_PAGO) asegurando trazabilidad financiera.

¿Cómo conectar con Cloudflare Tunnel?

1. Inicia tu backend con docker compose up -d
2. Lanza el túnel: cloudflared tunnel --url http://localhost:8000
3. Copia la URL generada (https://*.trycloudflare.com) y pégala aquí.
